# Jokoding — Yang Running Cuma Deadline

Durasi: 60 detik. Format: Reels vertikal 9:16. Sketsa animasi dengan dialog tertulis, musik elektronik ringan, dan efek bunyi orisinal. Ilustrasi mahasiswa adalah karakter fiksi. Referensi Instagram tidak dapat diakses; penyutradaraan mengikuti brief pengguna dan identitas visual gambar terlampir.

| Waktu | Adegan / dialog di layar |
|---|---|
| 00–04 | Mahasiswa percaya diri. “TUGAS INI GAMPANG…” / “Kata dosen.” |
| 04–09 | Masih percaya diri. “Cuma bikin aplikasi kecil.” / “Kecil aplikasinya. Besar cobaannya.” |
| 09–14 | Layar merah, mahasiswa panik. “23.47 • DEADLINE 00.00” / “5 error. 1 malam. 0 ketenangan.” |
| 14–19 | Mencoba memperbaiki. “Tutorial: tinggal ikuti langkah ini.” / “Aku: siap, ini mah beres.” |
| 19–24 | Error bertambah, zoom wajah. “5 ERROR → 12 ERROR” / “Bug-nya malah ngajak keluarga.” |
| 24–30 | Berdebat dengan laptop. “Aku: ayo dong, RUN!” / “Laptop: yang running cuma deadline.” |
| 30–36 | Teman memberi saran, mahasiswa membuka ponsel. “Bro, coba order di Jokoding.” / “Plot twist: ada jalan keluarnya.” |
| 36–42 | Mahasiswa menyiapkan chat. “Kirim brief + error + deadline.” / “Tanya dulu kebutuhan & pengerjaannya.” |
| 42–48 | Mahasiswa kembali belajar dengan lega. “Biar nggak cuma asal jalan…” / “Pahami juga kenapa tadi error.” |
| 48–54 | Laptop menyala hijau, mahasiswa tersenyum. “Kode: running.” / “Aku: akhirnya bisa rebahan.” |
| 54–60 | CTA dengan payoff. “ERROR JANGAN DIPELIHARA.” / “Order? DM @jokodingg” / “Yang dipelihara cukup kucing.” |

Caption unggahan:

Niatnya benerin satu bug. Yang datang malah satu keluarga. 🫠

Lagi mentok ngerjain koding? Kirim brief, screenshot error, dan deadline kamu lewat DM @jokodingg. Diskusikan kebutuhanmu, lalu pahami juga solusinya.

Pernah error-nya nambah setelah “diperbaiki”? Cerita di komentar 👇
